# 卦象關係深度指南：應、承乘、互卦、錯卦、綜卦、變卦
# 快速參考：六種關係的作用
 關係  定義  作用  何時看
 應  初↔四、二↔五、三↔上  有沒有外援  問合作、求助
 承乘  相鄰兩爻上下關係  上下關係順不順  問職場、輩分
 互卦  爻2-5組成的卦  內在本質（最重要！） 每次必看
 錯卦  陰陽全反  互補視角  看對立統一
 綜卦  上下顛倒  對方視角  問感情、談判
 變卦  動爻變化後的卦  發展趨勢  有動爻時
# 一、應（對應爻）— 看外援
# 對應關係
初爻 ←→ 四爻
二爻 ←→ 五爻  ← 最重要（君臣相應）
三爻 ←→ 上爻
# 判斷規則
- 一陰一陽 = 有應（有人幫）
- 兩陽或兩陰 = 無應（孤軍奮戰）
- 三組相應中，二五（中位相應）份量最重；初四次之，三上最輕
# 占卜應用
- 問事業：看體卦與用卦的二五爻是否有應
- 二五有應：有貴人、資源到位、合作順利
- 二五無應：需自力更生、缺乏外援
# 二、承乘 — 看上下關係
# 定義
承 = 下爻承托上爻
乘 = 上爻騎乘下爻
# 四種組合
 類型  意義
 陽乘陰  剛統柔，最順
 陰承陽  柔順剛，平衡
 陽承陰  剛在柔下
 陰乘陽  柔凌剛，最危
# 化解「陰乘陽」
三者具二即可轉吉：得中 + 得尊位 + 合時義
# 占卜應用
- 看體卦動爻與相鄰爻的陰陽關係
- 陰乘陽出現時：提醒問卦者注意上下關係、權力結構
# 三、互卦 — 看內在本質（最重要！）
# 計算方法
下互卦 = 爻 2, 3, 4
上互卦 = 爻 3, 4, 5
# 為何最重要
六種關係中，互卦與本卦的內涵最貼近，是本卦「藏在裡面的樣子」，故解卦時最值得參看。
# 時間意義
- 用卦 = 近期（當前狀態）
- 互卦 = 中期（發展過程、真正走向）
- 變卦 = 遠期（最終結果）
# 占卜應用
- 每次解卦必看互卦
- 本卦吉但互卦凶 = 表面好但有隱患
- 本卦凶但互卦吉 = 困難中有出路
- 互卦生體 = 過程中有助力
- 互卦克體 = 過程中有阻礙
# 四、錯卦 — 看互補面
# 定義
所有爻陰陽互換
# 讀法
不是「對立」而是「互補」——錯卦是同一件事的另一面，不是反面判詞。
# 常見錯卦對
 本卦  錯卦  關係
 乾  坤  創造 ↔ 承載
 泰  否  通泰 ↔ 閉塞
 既濟  未濟  完成 ↔ 未完
# 占卜應用
- 理解事物的另一面
- 看到現象的互補性質
# 五、綜卦 — 看對方視角
# 定義
整卦 180 度翻轉
# 爻位對應
本卦初爻 ↔ 綜卦上爻
本卦二爻 ↔ 綜卦五爻
本卦三爻 ↔ 綜卦四爻
# 自對稱卦（綜卦即本卦）
乾、坤、頤、大過、坎、離、中孚、小過
# 占卜應用
- 問感情/談判：把卦倒過來看對方視角
- 你在初爻 → 對方在上爻
- 理解對方處境後更容易找到共識
# 六、變卦 — 看發展趨勢
# 計算方法
動爻陰陽互換後形成新卦
# 陰爻 vs 陽爻變化
 爻性  占卜建議
 陰爻動  變化較安全（柔動則順）
 陽爻動  需謹慎評估（陽極必反）
# 各爻位變化特性
 爻位  占卜建議
 三爻  本多凶，動則易轉機——窮則變，變則通
 初爻  起步未穩，變動風險高
 二、五爻  得中得尊，守成者慎動
# 占卜應用
- 陰爻動 → 較安全
- 陽爻動 → 需謹慎
- 三爻動且本凶 → 不必過慮，變後可能轉好
- 二五爻動且本吉 → 考慮是否真需要變動
- 動爻凶但變卦好 = 窮則變，變則通
- 動爻吉但變卦差 = 居安思危
# 解卦優先順序
# 權重排序（由重到輕，質性排序非計分）
1. 時義     ← 卦的整體主題
2. 爻位     ← 動爻在什麼位置
3. 得中     ← 是否二或五
4. 應       ← 有沒有外援
5. 承乘     ← 上下關係順不順
6. 當位     ← 陰陽是否得位
# 完整解卦公式
完整解讀 = 本卦（現狀）
         + 動爻（轉折點）
         + 變卦（結果）
         + 互卦（內在本質，最重要！）
         + 應爻（外援）
         + 綜卦（對方視角，選用）
# 與梅花易數體用的結合
# 體用 + 六種關係
 步驟  看什麼  目的
 1  體用生克  基本傾向
 2  互卦生克  中期走向（最重要）
 3  變卦生克  最終結果
 4  二五應  有無外援
 5  承乘關係  上下是否順
 6  綜卦  對方視角（選用）
# 範例
問：這次合作會成功嗎？
1. 體用：體卦震木，用卦坎水，水生木 → 基本有利
2. 互卦：若互卦為離火，木生火（體生互）→ 過程中有付出
3. 變卦：若變卦為乾金，金克木（變克體）→ 最終有阻礙
4. 二五應：若有應 → 合作方會配合
5. 承乘：若動爻陰乘陽 → 可能有人不服
6. 綜卦：倒過來看 → 對方視角如何

通關化解
體用相克時，互卦或變卦有通關元素可緩解凶象。
通關=能同時與兩個相克元素產生生關係的第三元素
通關對照表
克關係|通關|原理|卦象
金克木|水|金生水水生木|乾兌→坎→震巽
木克土|火|木生火火生土|震巽→離→坤艮
土克水|金|土生金金生水|坤艮→乾兌→坎
水克火|木|水生木木生火|坎→震巽→離
火克金|土|火生土土生金|離→坤艮→乾兌
通關應用
1確定體用關係（克關係則繼續）
2查看互卦變卦是否有通關元素
3有通關凶象減輕，無則維持
通關歌訣
金木相爭水通關，木土相克火當先。土水交戰金為媒，水火不容木來援。火金相搏土調停，五行通關化凶煞。
